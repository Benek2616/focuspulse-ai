# ◉ FocusPulse AI

Nowoczesny timer Pomodoro z historią sesji, dziennym celem i inteligentnymi wskazówkami.

## Funkcje

- Klasyczny cykl Focus / Krótka przerwa / Długa przerwa
- Automatyczne przełączanie po zakończeniu sesji
- Śledzenie minut i liczby sesji w ciągu dnia
- Pasek postępu do dziennego celu
- Dynamiczne insighty zależne od Twojego postępu
- Możliwość dostosowania czasów i celu
- Powiadomienia systemowe + dźwięk na koniec sesji
- Dane zapisywane lokalnie (localStorage)
